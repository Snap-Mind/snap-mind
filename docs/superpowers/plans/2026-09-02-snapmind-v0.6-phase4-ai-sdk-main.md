# SnapMind v0.6 Phase 4 — `@ai-sdk` + AI in main Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every model call into the main process on `@ai-sdk` `streamText`, with stream-id IPC, no renderer adapters, and no provider model-list API.

**Architecture:** Renderer sends `{ agentId, messages }`. Main re-resolves the agent, decrypts the key, builds a LanguageModel from `provider.kind`, and pushes `ai:token` / `ai:reasoning` / `ai:source` / `ai:done` / `ai:error`. `electron/` is grouped into `ai/`, `ipc/`, `services/`. Unpackaged builds write debug AI logs to the electron-log file.

**Tech Stack:** Electron ESM, TypeScript, Vitest + jsdom, `ai`, `@ai-sdk/openai`, `@ai-sdk/anthropic`, `@ai-sdk/google`, `@ai-sdk/azure`, `@ai-sdk/openai-compatible`, `ollama-ai-provider`.

**Spec:** [`docs/superpowers/specs/2026-08-31-snapmind-v0.6-phase4-ai-sdk-main-design.md`](../specs/2026-08-31-snapmind-v0.6-phase4-ai-sdk-main-design.md)

## Global Constraints

- Read the spec before starting. Do not implement Phase 5 tools or `ai:tool-call`.
- Node `>=24 <25`. Native ESM. Relative imports in `main.ts`, `electron/**`, and `preload.ts` keep `.js` extensions.
- Three TS targets: `tsconfig.main.json`, `tsconfig.preload.json`, `tsconfig.json`. Put code in the right one.
- `preload.ts` + `src/types/index.d.ts` are the IPC contract. New channels must land in both.
- **File names:** PascalCase for a class/service (`AIService.ts`). camelCase for functions (`createLanguageModel.ts`, `registerAiIpc.ts`). Spec §2.1.
- **Icons** still go through `src/components/Icon.tsx`.
- Ollama needs no API key. No silent model fallback. Unresolvable agents use today's `agentErrorMessage` copy.
- Never log API keys, `Authorization`, or raw request bodies. Use `redact.ts`.
- Do not bump `package.json` version until Task 13.
- Agents work is closed (`0.6.0-beta.3` + `0.6.0-beta.4`). Do not reopen the Agents editor unless a compile error forces a one-line import fix.
- Run `npx vitest run <files>` at the end of every task. Run `npm run lint` before each commit.
- Commit after every task with Conventional Commits (`feat(ai):`, `refactor(electron):`, `fix(log):`).

## Task 8: `AIService` (main)

**Files:**

- Create: `electron/ai/AIService.ts`
- Test: `electron/ai/__tests__/AIService.test.ts`

**Interfaces:**

```ts
import type { Message } from '../../src/types/chat';
import type { AgentsService } from '../services/AgentsService.js';
import type { ProvidersService } from '../services/ProvidersService.js';
import type { LanguageModel } from 'ai';

export type AiSendErrorCode =
  | 'no-agent'
  | 'unbound'
  | 'missing-model'
  | 'no-api-key'
  | 'unknown_kind'
  | 'send_failed';

export type AiSendResult =
  | { streamId: string }
  | { error: { code: AiSendErrorCode; message: string } };

export type AiStreamHandlers = {
  onToken: (text: string) => void;
  onReasoning: (text: string) => void;
  onSource: (source: { url: string; title?: string }) => void;
  onDone: (reason: 'stop' | 'aborted') => void;
  onError: (message: string) => void;
};

export type StreamTextFn = (opts: {
  model: LanguageModel;
  messages: unknown;
  abortSignal: AbortSignal;
  temperature: number;
  maxOutputTokens: number;
  topP: number;
}) => { fullStream: AsyncIterable<unknown> };

export class AIService {
  constructor(
    private agents: AgentsService,
    private providers: ProvidersService,
    private deps: {
      streamText: StreamTextFn;
      createLanguageModel: typeof import('./createLanguageModel.js').createLanguageModel;
    }
  ) {}

  send(
    agentId: number,
    messages: Message[],
    handlers: AiStreamHandlers
  ): Promise<AiSendResult>;

  abort(streamId: string): void;
}
```

Behavior:

- One in-flight stream. `send` aborts the previous controller first.
- Resolve via `agents.list()` + `providers.list()` and the same rules as `resolveAgent` (copy the logic into `electron/ai/resolveAgentForRun.ts` if that keeps `AIService.ts` small — PascalCase only if it is a class; this helper is camelCase `resolveAgentForRun.ts`). Reuse the **same user-facing strings** as `agentErrorMessage` in `src/services/agentResolver.ts`.
- On resolve failure: return `{ error }` and do not call `streamText`.
- On success: `streamId` = `crypto.randomUUID()`, store `AbortController`, call `streamText` with mapped messages/params, iterate `fullStream`.
- Map SDK part types (adjust to the installed SDK; tests use a fake async iterable):
  - `text-delta` / `{ type: 'text-delta', textDelta }` → `onToken`
  - `reasoning-delta` → `onReasoning`
  - `source` → `onSource`
- Catch abort → `onDone('aborted')`. Other errors → `onError(message)` then do not throw from `send` after returning `{ streamId }` (the invoke already returned). `send` may return `{ streamId }` before the stream finishes; start the iterate loop without awaiting it (fire-and-forget Promise, log failures).
- Logging: `logService.scope('ai.send')` / `'ai.stream'` / `'ai.abort'` with `streamId`, `agentId`, `kind`, `modelId`. Token text only via `truncateDebugText` at debug. Pass objects through `redactValue`.

  2. Happy path emits token then `onDone('stop')`.
  3. `abort(streamId)` → `onDone('aborted')`.
  4. Fake stream throws → `onError`.

Use in-memory stubs, not SQLite, unless it is faster to reuse `makeTestDb` + real services.


`ElectronAPI` in `index.d.ts` gets those methods. Payload types from `ai-ipc.ts`.
